# Resolução de Desafios em C#
Este repositório contém a resolução de diversos desafios de lógica e programação em C# para o desafio de vaga da Target Sistemas, organizados por pastas. 
Cada pasta representa uma questão individual.

## Estrutura do projeto
Todos os arquivos estão em suas pastas Nomeadas dentro do arquivo "Program.cs"
- Questão 1 - Execução de estrutura semi pronta de codigo para descobrir o resultado final.
- Questão 2 - Permite a entrada de um numero e verifica se ele pertence a sequencia de Fibonacci.
- Questão 3 - Lê um arquivo do tipo Json e calcula os dias de maior e menor faturamentos alem dos dias acima da média.
- Questão 4 - Calcula o faturamento percentual por estado com os dados citados na questão.
- Questão 5 - Permite a entrada de uma palavra e faz a inversão da mesma sem utilizar funções prontas

## Como executar

1. Abra o terminal na pasta da questão desejada. Ex: "Questao1"
2. Compile e execute com os seguintes comandos:

```bash
dotnet build
dotnet run
```
3. Siga o passo a passo descrito no console.
- obs: Algumas questões não requerem que sejam inputados dados, portanto elas so exibem o resultado final.
